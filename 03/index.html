01

시공간 제약 극복

🏢 현실세계 (물리적 한계)

특정 장소에 직접 가야만 활동이 가능하고 정해진 시간에 얽매임

🌐 가상공간 특징

시간과 공간에 상관없이 교육, 문화, 금융, 의료 등의 일을 편리하게 진행하며 멀리 떨어진 사람과 실시간 정보 공유 가능

📌 연관된 대응 카드 목록 (중복 포함)
02

익명성

👤 현실세계 (정체성 노출)

대면 만남으로 신분, 나이, 사회적 지위 등이 쉽게 드러남

🎭 가상공간 특징

자신의 신분이나 정체성을 드러내지 않고 활동할 수 있으며, 자신의 의견을 자유롭게 제시하고 평등하게 소통함

📌 연관된 대응 카드 목록 (중복 포함)
03

개방성

🚧 현실세계 (공간적 한계)

주변의 한정된 사람들과 관계를 맺고 소수 생산자가 일방적 정보 전달

🌐 가상공간 특징

누구나 정보를 이용·생산·유통하며, 현실에서 만나기 어려운 사람들과 소통해 풍부한 인간관계를 맺음
